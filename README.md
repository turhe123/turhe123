- **[animi](https://github.com/turhe123/animi)**: a lightweight 4K/8K video wallpaper and idle screensaver engine for macOS and Windows, built with Rust and Tauri.

## How the collections are built

The apps and web tools in the two collections were written by Claude Code inside an automated pipeline I built, from plain-English specs, as clean-room implementations: no code or assets from any commercial product. Every web tool must pass a headless browser test suite (zero console errors, no third-party traffic, phone layout, dark theme, offline) and an independent review before it is published, and every README says so in a "Built with AI" section. They have had less human review than hand-written software, so bug reports and pull requests are welcome on each repo.
